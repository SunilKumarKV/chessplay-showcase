# Contributing to ChessPlay Showcase

Thank you for contributing.

## Repository Scope

This repository is a public showcase for ChessPlay. It should contain only sanitized product presentation assets, documentation, screenshots, and public-facing roadmap information.

Do not add:

- production secrets
- private backend code
- database credentials
- payment logic
- admin logic
- private deployment configuration
- sensitive Socket.IO server implementation details

## Contribution Rules

- Keep changes focused on public documentation and showcase quality.
- Do not commit `.env` files.
- Do not expose production API keys, tokens, or URLs that should remain private.
- Keep screenshots clean and free from private user data.
- Update README when product positioning or live links change.

## Pull Requests

Use the pull request template and include screenshots for visual changes.
